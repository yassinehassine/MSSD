📊 DEPLOYMENT SCENARIOS SUPPORTED:

1. Development (HTTP):
   - File: docker-compose.yml (existing)
   - Best for: Local development
   - Command: docker-compose up -d

2. Production Single Server (HTTPS):
   - File: docker-compose.ssl.yml (new)
   - Best for: Production deployment
   - Command: docker-compose -f docker-compose.ssl.yml up -d

3. Production with Monitoring:
   - File: docker-compose.ssl.yml + --profile monitoring
   - Best for: Production with Prometheus/Grafana
   - Command: docker-compose -f docker-compose.ssl.yml --profile monitoring up -d

4. Clustered Deployment:
   - File: docker-compose.prod.yml (existing)
   - Best for: Docker Swarm/large scale
   - Command: docker stack deploy -c docker-compose.prod.yml mssd
